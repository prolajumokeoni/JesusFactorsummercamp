# Summer Camp Website

A simple, responsive website built by campers to showcase what they learned.

## Structure
- **index.html** — Home page with hero, slideshow gallery, testimonials, and animated counters.
- **about.html** — About the camp + extra testimonials.
- **projects.html** — Grid of campers' projects with images.
- **style.css** — Styles (mobile-first, responsive, with animations).
- **script.js** — JS for hamburger menu, scroll reveal, slideshow, and counters.
- **assets/** — Images and logo (SVG placeholders you can replace).

## How campers can contribute
1. Edit text directly in the `.html` files.
2. Replace images in `assets/images/` (keep file names or update the `src` paths).
3. Add new project cards in `projects.html` by duplicating a `.project-card` block.

## Run locally
Just open `index.html` in a browser. No build step needed.

## Deploy (GitHub Pages)
1. Create a GitHub repo and push these files.
2. In GitHub: **Settings → Pages → Source: `main` / `/ (root)`**.
3. Your site will get a public URL in a minute or two.
